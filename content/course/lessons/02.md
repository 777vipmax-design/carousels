# Урок 2. Первый запуск за 15 минут

Программировать не нужно — всё установит Claude Code. Твоя задача — открыть папку и дать ему задание.

**Шаг 1.** Установи Claude Code (desktop-приложение Claude или терминальную версию — инструкция на сайте Anthropic).

**Шаг 2.** Открой в нём папку «Автомонтаж» и отправь:
> Это набор для автомонтажа рилсов. Прочитай README.md. Установи всё, что нужно для make.py (Python, ffmpeg, playwright с chromium), и запусти: python make.py script.json. Если будут ошибки — исправь и запусти снова. В конце покажи, где лежит final.mp4.

**Шаг 3.** Подожди 3–5 минут. Claude сам поставит программы, запустит сборку и покажет готовый файл.

**Что получится:** final.mp4 — 20-секундный пример с голосом, сценами, субтитрами и звуками, плюс cover.png — обложка.

**Если что-то пошло не так**
- «command not found: python» → попроси Claude: «установи Python и повтори»
- «ffmpeg not found» → «установи ffmpeg и повтори»
- зависло на «кадры …» → это нормально: кадры рисуются по одному, 20 секунд видео ≈ 1–2 минуты

**Домашка:** собери пример и посмотри final.mp4 на телефоне. Пришли в бота «готово» — а дальше делаем твой ролик.
