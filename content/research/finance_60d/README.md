# Финграмотность, долги, кредиты — RU, 60 дней (17.08–16.10.2026)

| Файл | Что внутри |
|---|---|
| `fin_reels_ru_60d.csv` | 31 ролик (28 Instagram Reels + 3 YouTube Shorts), по просмотрам |
| `top15_questions.md` | 15 частых вопросов из комментариев, дословно |
| `top10_youtube_channels.md` | 10 крупнейших YouTube-каналов + 3 быстрорастущих |

Колонки CSV: платформа · ссылка · автор · дата · просмотры · лайки · комментарии · хук · тема в 5 словах · прямая реклама займов (да/нет) · что продаёт вместо займов · куда ведёт.

## Главное
- **Прямой рекламы займов/МФО — 0 из 31.** Ниша монетизируется иначе: **услуги банкротства** (khulueva_urist, danil.expert, ignatievbob, nadezhda_bankrotstvo), **кредитные/ипотечные брокеры** (elena_trillion), **юрконсультации** (suleimanova.law, an_maevskaya). У danil.expert в каждой подписи дисклеймер «не предлагает финансовые продукты».
- **Куда ведут:** почти всегда — **кодовое слово → директ** («Выход», «Помощь», «Тест», «Выписка», «Банки», «+», «любой комментарий»). Ссылок на сайты и ботов в подписях нет (Telegram — только у «Простой экономики» и в шапках профилей).
- **Топ по охвату — личные истории про деньги, а не советы юристов**: бюджет семьи по конвертам (1,2 млн), «не платила кредиты на 1,5 млн» (657 тыс.), «на мне 60 микрозаймов» (211 тыс.), кредит на свадьбу (207 тыс.).
- Юристы набирают 50–300 тыс. на хуках-новостях: «Президент разрешил списать долги», «Срочная новость для людей с долгами», «Дадут ли кредит после банкротства?».

## Ограничения (честно)
- **YouTube Shorts почти не собрались**: поиск YouTube по этим темам отдаёт в основном ролики 1–4-летней давности; за 60 дней с заметными просмотрами нашлось только 3 (фильтр «за месяц» в веб-поиске Shorts работает плохо).
- **Темы «как проверить МФО» и «рефинансирование»** почти не дают свежих популярных роликов ни в Instagram, ни в YouTube — есть 1–2 ролика с 20–50 тыс.
- Просмотры Instagram — со вкладки Reels автора; у 3 роликов «н/д» (не попали в видимую часть).
- «Хук» — текст первого кадра (звук не слушал).
- Несколько роликов юристов-блогеров оказались не по теме (светская драма, пособия) — в таблицу не включены.
