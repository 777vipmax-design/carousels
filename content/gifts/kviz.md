# Квиз для сайта

## Запрос
> Сделай квиз для сайта [ниша] одним файлом HTML: 4 вопроса с вариантами ответов и картинками-иконками, полоса прогресса, в конце — подарок «[скидка/расчёт/чек-лист]» и форма (имя, телефон, удобный мессенджер). Ответы клиента приходят вместе с заявкой. Цвета: [ ]. Мобильная версия обязательна.

## Вопросы для ниш
- **Ремонт:** тип жилья → площадь → тип ремонта → когда начать
- **Окна:** сколько окон → тип дома → нужен ли монтаж → сроки
- **Обучение:** цель → уровень → формат → когда начать
- **Свадьба:** дата → гостей → бюджет → стиль
