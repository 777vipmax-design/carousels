# Как не потерять работу в Claude Code

## Откат за 2 секунды
- **Esc, Esc** или команда `/rewind` → выбери точку → откатить разговор, код или и то и другое.
- Точки Claude Code сохраняет сам по ходу работы.

## Надёжная страховка — версии в git
Запрос:
> После каждого шага, который работает, сохраняй версию в git с понятным описанием на русском. Перед большими изменениями — сделай отдельную ветку.

Вернуться:
> Покажи последние 10 версий и верни проект к той, где работала форма заявки.

## Если всё сломалось
1. Не проси «исправь всё» — опиши, что видишь: скриншот или текст ошибки.
2. «Что ты поменял за последние 3 шага?»
3. Не помогло — откат к последней рабочей точке.
