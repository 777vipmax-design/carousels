# Чек-лист безопасности для сайта, сделанного с нейросетью

1. **Ключи от сервисов** (оплата, почта, нейросети) — только на сервере, в файле .env. Никогда в коде страницы и не в публичном репозитории.
2. **.env в .gitignore** — чтобы ключи не улетели на GitHub.
3. **Пароли** — только в виде хэша (bcrypt/argon2), не открытым текстом.
4. **Админка** — под паролем, лучше с двухфакторным входом; не по «секретной» ссылке.
5. **Формы** — проверка данных на сервере, защита от спама.
6. **Лимит расходов** на всех платных API — чтобы утечка ключа не стоила тысяч.
7. **Резервные копии** базы.
8. **HTTPS** везде.

## Запрос для проверки
> Проверь этот проект на уязвимости: ключи и секреты в коде, хранение паролей, доступ к админке, проверка данных в формах, что попадает в репозиторий. Для каждой проблемы: где она, чем опасна простыми словами, как исправить. Начни с самых опасных.

Если на сайте собираются данные людей — дополнительно покажи его специалисту.
