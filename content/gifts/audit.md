# Быстрая SEO-проверка страницы

## Запрос
> Проверь страницу [адрес] под запрос «[главный запрос]». Оцени: title и description (длина, есть ли запрос и город), H1, структуру заголовков, отвечает ли страница на вопросы клиента (цена, сроки, адрес, контакты), есть ли призыв к действию. Дай исправленные title, description и H1 и список того, что добавить в текст.

## Чек-лист страницы
- title до ~60 символов, с запросом и городом
- description — выгода + призыв
- один H1
- цены или «от …»
- адрес, часы, телефон
- отзывы, фото работ
- быстрая загрузка на телефоне

Это базовая проверка. Индексацию, скорость и ссылки смотри в Яндекс Вебмастере и Search Console.
