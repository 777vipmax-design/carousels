# Как я настроил автомонтаж с Claude

## Что получается на выходе
Ролик 9:16 с субтитрами, вставками-анимациями, музыкой и звуками. Я только записываю себя на телефон.

## Схема (один раз настроить — дальше одной фразой)
1. **Запись.** Снимаю одним куском, с оговорками и паузами — неудачный дубль просто повторяю.
2. **Распознавание.** Claude Code прогоняет звук через бесплатную модель распознавания речи (whisper) и получает текст с таймингами каждого слова.
3. **Чистка.** По паузам находит, где я споткнулся и повторил фразу, — оставляет последний удачный дубль.
4. **Субтитры.** Режет текст на короткие фразы по 2–4 слова, подсвечивает слово, которое звучит сейчас.
5. **Вставки.** На каждую мысль рисует анимированную карточку (обычная веб-страница → видео).
6. **Музыка и звуки.** Музыка фоном тише голоса, «вжух» на смене сцен, щелчки на появлении элементов.
7. **Сборка.** Всё склеивается в один файл, обложка — первым кадром.

## Запрос, с которого начать в Claude Code
> Вот видео, где я говорю на камеру. Сделай из него рилс 1080×1920: убери паузы и неудачные дубли, добавь субтитры по 2–4 слова с подсветкой текущего слова, на каждую мысль — анимированную карточку сверху, лицо снизу. Музыку возьми из music.mp3 и сделай тише голоса. Сначала покажи план монтажа текстом, потом собирай.

## Если что-то не так
> Субтитры отстают от голоса к концу — проверь, что каждый кусок режется по целым кадрам.
> Фраза звучит дважды — найди повтор по паузам и оставь только второй дубль.
