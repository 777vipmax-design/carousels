# 5 запросов для голосовых заметок

Нажми микрофон в приложении Claude и говори как есть — потом одна из фраз:

1. **План на день:** «Разложи то, что я надиктовал, по приоритетам и времени. Срочное — сверху».
2. **Пост из мысли:** «Сделай из этого пост для Instagram: хук, 3 пункта, вопрос в конце. Мой стиль — простой и живой».
3. **Письмо клиенту:** «Сделай из этого вежливое письмо клиенту, коротко и по делу».
4. **Конспект встречи:** «Сделай конспект: решения, задачи с ответственными и сроками, открытые вопросы».
5. **Разбор головы:** «Я устал и всё в куче. Выдели 3 главные задачи на завтра, остальное — в список „потом“».
