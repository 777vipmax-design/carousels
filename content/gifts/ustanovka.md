# Как установить скилл в Claude

## В приложении (claude.ai, компьютер или телефон)
1. Настройки → Возможности (Capabilities) → включи «Выполнение кода и создание файлов».
2. Подготовь скилл: папка с файлом SKILL.md внутри. Имя папки = имя скилла.
3. Запакуй ПАПКУ в .zip (не файлы по отдельности, а саму папку).
4. Раздел «Скиллы» (Customize → Skills) → «+» → «Создать скилл» → «Загрузить скилл» → выбери zip.
5. Скилл появится в списке — проверь, что переключатель включён.

Скиллы доступны на всех тарифах, включая бесплатный. На командных тарифах их сначала разрешает владелец.

## В Claude Code
Положи папку сюда:
- для одного проекта: `.claude/skills/имя-скилла/SKILL.md`
- для всех проектов: `~/.claude/skills/имя-скилла/SKILL.md`

## Частые ошибки
- в архиве нет папки, только файлы → не загрузится
- имя папки не совпадает с именем в SKILL.md
- выключено «Выполнение кода»
- в названии скилла лишние символы

## Проверка
Напиши Claude: «Какие скиллы у тебя сейчас включены?»
