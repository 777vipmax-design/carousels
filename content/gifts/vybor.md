# 5 задач для честного сравнения нейросетей

Дай одну и ту же задачу обеим и сравни ответы рядом.

1. **Текст:** «Напиши пост про [мой бизнес] для [аудитория], до 600 знаков».
2. **Документ:** загрузи свой договор или отчёт — «перескажи главное и найди риски».
3. **Таблица:** «Вот данные [ ]. Сделай таблицу с итогами и выводами».
4. **Код:** «Сделай одностраничный сайт для [бизнес]».
5. **Длинная задача:** план на месяц по шагам.
