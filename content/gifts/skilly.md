# 5 скиллов, которые превращают Claude в команду

Скиллы (skills) — официальные навыки от Anthropic, создателей Claude. Это готовые инструкции: Claude подгружает их сам, когда задача подходит. Отдельно за скиллы платить не нужно.

## Как включить

**В приложении или на сайте Claude**
1. Settings → Capabilities (Настройки → Возможности) → включи «Code execution and file creation».
2. Customize → Skills (Настроить → Навыки) → включи нужные скиллы.
3. Word, Excel, PowerPoint и PDF работают сами, когда ты просишь такой файл.

**В Claude Code (для тех, кто работает в терминале)**
```
/plugin marketplace add anthropics/skills
/plugin install document-skills@anthropic-agent-skills
/plugin install example-skills@anthropic-agent-skills
```
Все скиллы лежат открыто: github.com/anthropics/skills

---

## 01 Дизайнер — frontend-design
Делает сайты и интерфейсы со своим стилем, а не «шаблон как у всех».
Пример запроса:
> Сделай одностраничный сайт для студии йоги. Настроение — тёплое утро, крупная типографика с засечками, без шаблонных карточек. Кнопка «Первое занятие бесплатно».

## 02 Презентации — pptx
Собирает готовый файл PowerPoint: слайды, структура, графики.
> Сделай презентацию на 8 слайдов «Итоги квартала» по этим цифрам: [вставь цифры]. Тёмная тема, один вывод на слайд.

## 03 Аналитик — xlsx
Таблицы Excel с формулами, графиками и итогами.
> Вот продажи по месяцам: [вставь]. Сделай таблицу Excel с ростом в %, итогом и графиком. Месяцы с падением выдели красным.

## 04 Художник — canvas-design
Постеры, обложки и афиши в картинке (PNG) и PDF.
> Сделай постер весеннего фестиваля в стиле швейцарского дизайна: крупные геометрические фигуры, заголовок «ВЕСНА», дата внизу.

## 05 Тренер — skill-creator
Создаёт НОВЫЕ скиллы. Опиши задачу, которую делаешь часто, — и Claude будет делать её по твоим правилам каждый раз.
> Создай скилл «отчёт для клиента»: беру выгрузку из таблицы, считаю итоги, оформляю отчёт в моём стиле — заголовок, 3 вывода, рекомендации.
