# Claude Code без терминала: первый запуск

1. Скачай приложение Claude для компьютера (Windows или Mac) с сайта claude.com и войди в аккаунт.
2. Вверху открой вкладку **Code**. Нужен платный тариф (Pro или выше).
3. Выбери **Local** → **Выбрать папку** → создай пустую папку для проекта.
4. Выбери модель рядом с кнопкой отправки.
5. Напиши задачу обычными словами.

## Первая задача
> Сделай одностраничный сайт-визитку для [бизнес]. Сначала задай мне 5 вопросов. Объясняй простыми словами, что делаешь.

## Режимы подтверждения (рядом с кнопкой отправки)
- **Manual** — спрашивает перед каждым изменением (для начала — лучший)
- **Accept edits** — сам правит файлы
- **Plan** — только план, ничего не меняет

Изменения видно в окне сравнения: что было и что стало. Можно принять или отклонить.
