# Запрос, с которого я начинаю проект в Claude Code

Включи режим плана: **Shift+Tab** (или команда `/plan`). В нём Claude только изучает и предлагает, ничего не меняет.

> Я хочу [что сделать]. Для кого: [ ]. Сначала задай мне вопросы, которых тебе не хватает. Потом изучи проект и предложи план: шаги, какие файлы изменишь, что может сломаться, как проверим результат. Ничего не меняй, пока я не скажу «делай».

## Как читать план
- Понятен ли каждый шаг? Если нет — «объясни шаг 3 проще».
- Нет ли лишнего? — «убери шаг 5».
- Есть ли проверка в конце?

Одобрил → выключи режим плана (Shift+Tab) → «делай по плану».
