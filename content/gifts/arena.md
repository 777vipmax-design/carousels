# Команда из Claude: моя настройка

## Идея
Вместо «один запрос — один ответ» Claude Code раздаёт задачу помощникам (субагентам): каждый делает свою часть в своём окне и возвращает короткий итог.

## Состав команды для текста
- **Исследователь** — собирает факты и источники.
- **Автор** — пишет черновик по фактам.
- **Критик** — ищет слабые места и ошибки.
- **Редактор** — собирает финал.

## Как создать (Claude Code)
Попроси прямо:
> Создай мне субагентов в папке .claude/agents: researcher, writer, critic, editor. Для каждого — короткое описание, когда его вызывать, и какие инструменты ему нужны. Исследователю — поиск в интернете, остальным — только чтение и запись файлов.

И запускай задачу:
> Напиши пост про [тема]. Используй команду: researcher → writer → critic → editor. Каждый пусть отдаёт итог не длиннее 10 строк.

## Как не спалить лимит
1. **Короткие отчёты.** Пиши «итог до 10 строк» — длинные ответы помощников съедают лимит главного окна.
2. **Модель попроще для рутины.** В настройке субагента можно указать модель — поиск и проверку отдай более лёгкой.
3. **Сначала план.** «Покажи план, кого и зачем вызовешь» — и убери лишних.
4. **Не больше 3–4 помощников** на одну задачу.
5. **Новая задача — новый чат.** Длинная переписка тоже тратит лимит.
