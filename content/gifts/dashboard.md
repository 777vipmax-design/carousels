# Дашборд из таблицы

## Запрос
> Вот выгрузка [продажи/заявки/расходы] (файл). Сделай интерактивный дашборд одной страницей: сверху 4 главные цифры с изменением к прошлому периоду, графики [по месяцам / по товарам / по менеджерам], фильтры [период, менеджер]. Внизу — 3 вывода текстом.

## Какие графики нужны
- динамика по времени — линия
- сравнение категорий — столбцы
- доли — не больше 5 частей
- топ-10 — горизонтальные столбцы

## Как обновлять
Сохрани запрос. Новый месяц → загружаешь новый файл в тот же чат или проект → «обнови дашборд».

Проверь 2–3 числа вручную с исходным файлом.
