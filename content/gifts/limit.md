# Как растянуть лимит Claude: шпаргалка

1. **Новая задача — новый чат.** Каждое сообщение «тянет» за собой всю переписку, длинный чат расходует больше.
2. **Собирай задачи в одно сообщение.** «Сократи текст, дай 3 заголовка и подпись» — вместо трёх сообщений.
3. **Файлы — в проект.** Прайс, примеры, описание компании загрузи в проект один раз. Повторно используемые материалы проекта расходуют лимит меньше.
4. **Конкретный запрос с первого раза:** для кого, какой формат, какой объём, пример.
5. **Проверяй перед отправкой** — одно уточнение = ещё одно сообщение.
6. **Следи за расходом:** Настройки → Использование (на платных тарифах видно лимит сессии и недели).

## Шаблон запроса, который экономит лимит
> Задача: [что сделать]. Для кого: [аудитория]. Формат: [список / таблица / текст до N знаков]. Пример того, что мне нравится: [вставь]. Если чего-то не хватает — задай все вопросы одним списком, а потом делай.

Источник советов — официальная справка Claude (раздел про лимиты).
