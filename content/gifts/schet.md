# Как не получить огромный счёт за API

1. **Лимит расходов** в кабинете каждого платного сервиса (нейросети, рассылки, карты). Плюс уведомление на 50% и 80%.
2. **Отдельный ключ на каждый проект** — утёк один, отключил только его.
3. **Ключи только на сервере**, в .env, не в коде страницы и не в репозитории.
4. **Ограничение запросов в коде** — не больше N в минуту с одного адреса.
5. **Остановка при ошибках** — если 5 ошибок подряд, код прекращает попытки, а не крутится всю ночь.
6. **Проверка после запуска** — первые дни смотри расход каждый день.

## Запрос
