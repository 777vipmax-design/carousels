# Свой первый скилл за 5 минут

## Что такое скилл
Папка с инструкцией (SKILL.md) и, при желании, примерами и шаблонами. Claude подключает его сам, когда задача подходит.

## Шаблон SKILL.md
```
---
name: otchet-klientu
description: Делает отчёт для клиента по выгрузке из таблицы. Используй, когда просят отчёт для клиента.
---
# Отчёт для клиента
1. Возьми выгрузку, посчитай итоги за месяц.
2. Сравни с прошлым месяцем (+/- в %).
3. Структура: заголовок, 3 главных вывода, таблица, рекомендации.
4. Тон: спокойный, без жаргона.
Пример хорошего отчёта — в файле example.pdf.
```

## Самый простой способ
Попроси Claude: «Создай мне скилл для задачи [ ], задай вопросы, а потом упакуй в zip». Потом загрузи его (см. инструкцию по слову УСТАНОВКА).

## Идеи скиллов
ответы клиентам в моём стиле · КП по шаблону · пост из голосовой заметки · отчёт по рекламе · проверка договора по моим правилам
