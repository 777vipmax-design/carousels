# Разбор рекламы с Claude

## Запрос для анализа
> Вот выгрузка статистики рекламы за [период] (файл). Посчитай по каждой кампании: расход, клики, заявки, цену клика, цену заявки, конверсию. Найди: где сливается бюджет, какие кампании/запросы без заявок, в какие дни и часы заявки дешевле. Выводы — 5 пунктов простым языком, с цифрами.

## Отчёт клиенту
> Сделай из этого отчёт для клиента на 1 страницу: что было, что получили, 3 главных вывода, план на следующий месяц. Без жаргона. Файл Word.

## Что проверить в цифрах
- Совпадают ли итоги с кабинетом (сверь 2–3 числа вручную).
- Заявки считаются одинаково (звонки + формы?).
- Период одинаковый во всех файлах.

Персональные данные клиентов (телефоны из заявок) в выгрузку не включай.
