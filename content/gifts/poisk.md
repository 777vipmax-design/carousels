# find-skills — скилл, который находит нужный скилл

**Автор:** Vercel Labs · каталог skills.sh · около 3,8 млн установок (по данным каталога на октябрь 2026).

Ты пишешь задачу обычными словами — скилл ищет подходящие скиллы в каталоге, смотрит рейтинг, установки и репутацию автора, предлагает лучший и ставит его.

## Установка (Claude Code)
```
npx skills add https://github.com/vercel-labs/skills --skill find-skills
```
Потом просто пиши Claude, что хочешь сделать, — он сам вызовет поиск.

## 10 запросов для поиска
1. Найди скилл, чтобы делать презентации из PDF-отчётов.
2. Есть скилл для монтажа коротких видео?
3. Найди скилл для работы с таблицами Excel и графиками.
4. Нужен скилл, который пишет тексты для соцсетей в моём стиле.
5. Найди скилл для проверки сайта на ошибки.
6. Есть скилл для обработки фотографий пачкой?
7. Найди скилл для оформления договоров по шаблону.
8. Нужен скилл, который делает обложки и баннеры.
9. Найди скилл для разбора статистики рекламы.
10. Есть скилл, который превращает голосовые заметки в текст и план?

## Важно
Перед установкой смотри, кто автор и сколько у скилла установок. Ставь из проверенных источников — скилл получает доступ к твоим файлам в проекте.

## Топ официальных скиллов для работы
frontend-design · pptx · xlsx · docx · pdf · canvas-design · skill-creator — они лежат в github.com/anthropics/skills.
