# Плагины Claude Code: установка и настройка

## Что это
Плагин — пакет из скиллов, команд, помощников (агентов) и подключений. Ставится одной командой.

## Установка
1. Запусти Claude Code в папке проекта.
2. Введи `/plugin` → вкладка **Discover** → начни печатать название → **Enter**.
3. Прочитай, что плагин добавит (**Will install**), выбери, для кого ставить: для себя во всех проектах, для этого проекта или только локально.
4. Проверь: напиши `/` — команды плагина появятся в списке.

Официальный каталог Anthropic называется `claude-plugins-official`, он подключается сам при первом запуске. Сторонние каталоги добавляются командой `/plugin marketplace add владелец/репозиторий` — ставь только то, чему доверяешь: плагин может запускать команды.

## Как не спалить лимит
- В карточке плагина из официального каталога есть **Context cost**: сколько токенов он добавляет к каждому сообщению и при вызове.
- Во вкладке **Installed** есть раздел «Не использовались недавно» — отключай лишнее (пробел).
- Не ставь 10 плагинов «на всякий случай».
