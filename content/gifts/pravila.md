```
- Отвечай по-русски, просто, без жаргона.
- Перед большими изменениями — покажи план.

## Правила
- Не трогай папки: [old/, backup/]
- Файлы называй: [латиницей, через дефис]
- Секреты только в .env, никогда в коде.
- После правок — открой сайт и проверь, что всё работает.
- Работает — сохрани версию в git с понятным описанием.

## Важное о проекте
- Хостинг: [где]
- Цвета и шрифты: [ ]
- Что уже пробовали и не сработало: [ ]
```

## 10 полезных правил
1. Сначала план, потом код. 2. Одна задача — один шаг. 3. Объясняй, что сделал. 4. Не удаляй без спроса. 5. Проверяй на телефоне. 6. Не меняй дизайн без просьбы. 7. Пиши, если не уверен. 8. Сохраняй версии. 9. Не ставь лишние библиотеки. 10. Обновляй этот файл, когда находишь ошибку.
