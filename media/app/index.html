YT Analytics

Личное служебное приложение владельца YouTube-каналов. Приложение читает статистику собственных каналов владельца (просмотры, лайки, комментарии, удержание, подписки) через YouTube Data API и YouTube Analytics API, чтобы анализировать контент.

Доступ только на чтение. Приложение не публикует, не изменяет и не удаляет видео, не используется третьими лицами и не передаёт данные никому.
