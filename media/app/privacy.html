Политика конфиденциальности YT Analytics

Дата: 18 октября 2026 года.

Какие данные

Приложение получает с разрешения владельца канала только данные его собственных YouTube-каналов: название и идентификатор канала, список видео, публичную статистику (просмотры, лайки, комментарии) и аналитику YouTube Analytics (время просмотра, средняя длительность и процент досмотра, подписки, репосты). Используются области доступа только на чтение: youtube.readonly и yt-analytics.readonly.

Зачем

Данные используются исключительно владельцем каналов для анализа своего контента и планирования публикаций.

Хранение и защита

Токен доступа и статистика хранятся на частном сервере владельца в закрытых файлах, доступных только администратору. Данные не продаются, не передаются и не раскрываются третьим лицам и не используются для рекламы.

Отзыв доступа и удаление

Доступ можно отозвать в любой момент на странице myaccount.google.com/permissions. После отзыва сохранённый токен перестаёт работать, а по запросу владельца удаляются и сохранённые данные.

Использование данных, полученных через API Google, соответствует Google API Services User Data Policy, включая требования Limited Use.
